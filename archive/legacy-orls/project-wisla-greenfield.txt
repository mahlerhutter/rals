#
# Why this example exists:
#   Greenfield development assets stress ORLS along four dimensions that
#   Operating and Ready-to-Build assets do not:
#   (a) what's being sold IS the optionality and the work-product — permits,
#       land rights, connection rights, development know-how — not the
#       physical asset, which doesn't exist yet,
#   (b) risk profile dominates the value calculation — each unresolved
#       milestone has a probability and a value-at-stake,
#   (c) operating_history is irrelevant; in its place must be a granular
#       development_milestone_tracker,
#   (d) financial story is binary: either the project gets to RTB and the
#       buyer realizes development margin, or one of the unresolved risks
#       materializes and the value collapses.
#
#   Poland 2026 is the canonical European late-stage development market:
#   grid connection scarcity, CfD-vs-PPA-vs-merchant optionality, evolving
#   land-use restrictions. This example tests whether ORLS can carry that
#   complexity in a structured form.
#

#   Connection Agreement procedure, voivodeship spatial planning rules).
